# Frozen public data and attribution

Retrieved 21 October 2026. `data_manifest.json` records original URLs and SHA-256 hashes. `source_manifest.json` additionally records research-paper versions; their copyrighted PDFs are excluded from Git and retained only in the local `.cache/literature/` directory.

## Arena

Source: [Arena Team, A Deep Dive into Recent Arena Data](https://arena.ai/blog/opendata-july2025) and [arena-human-preference-140k](https://huggingface.co/datasets/lmarena-ai/arena-human-preference-140k), revision `6322995ab34d7c2693e3f47dd13fa5caa0789a74`. License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

`raw/arena_numeric.parquet` contains 135,634 records and only model names, outcomes, evaluation order, language, a coding indicator, and timestamp. It excludes prompts, model responses, user identifiers, and session identifiers. The download uses HTTP byte-range access to selected Parquet columns, avoiding conversation content. It is a column-reduced derivative, not the original full dataset. First-round counts and matching exclusions are generated by the analysis.

## Epoch

Source: [Data on AI models](https://epoch.ai/data/ai-models), [Epoch Capabilities Index](https://epoch.ai/eci), and [Capabilities and benchmarking data](https://epoch.ai/benchmarks/use-this-data). Epoch permits data reuse with attribution under its stated Creative Commons attribution terms. Original external benchmark data retain their own terms. No benchmark questions or answers are used in the analysis.

`raw/epoch_models.csv` freezes model metadata and estimated costs; `raw/eci_scores.csv` freezes model-level ECI. The benchmark archive provides the numeric GPQA model-version scores used for an alternative capability measure. `edi_scores.csv` is an unused diagnostic download containing benchmark difficulties, not an alternative model capability measure.

`model_crosswalk.csv` is the reviewed Arena-to-Epoch mapping. Primary matches, qualified aliases, and unmatched models remain distinguishable. ECI is model-level: default reasoning budgets can differ across evaluations. `cost_matches.csv` lists exact cost matches and flags shared-training derivatives excluded from cost regressions.

These are public descriptive data. They do not contain quantities sold, observed profits, causal marginal research costs, control-failure probabilities, or physical human-extinction thresholds.

## Refreshing sources

Normal replication uses the checked-in frozen files. `replication/acquire_data.py` documents selective acquisition. Refreshes should be performed in a separate directory and reviewed before replacing frozen files or updating hashes. Changing snapshots changes the estimand and must not silently overwrite a replication.
