# One external referee pass

The authorized workflow is one submission to the user's prepared ChatGPT Pro browser session after the complete initial manuscript passes local checks. The submission bundles the actual manuscript, proofs, references, numerical methods, results, and a frozen public Git commit, rather than assuming ChatGPT can read a repository link.

The final request, completed report, point-by-point response, and reviewed commit are saved here after that pass. The review is advisory and is checked against the proofs and code before changes are accepted. It is not independent human peer review.
